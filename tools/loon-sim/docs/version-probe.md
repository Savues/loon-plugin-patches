# 版本探针 (version-probe) — 原理、模板与排障

> 配套工具: `version-probe.sh`（实测前置守护）· `probe-setup.py`（探针埋入/更新）
> 强校验: `check` v1.7.0 起（六项模板锁定，见下）

---

## 1. 它解决什么问题

终端 curl 测的是**设备已加载的配置**，不是仓库最新提交。没有探针时：

```
改仓库 → push → 用户更新订阅 → 抓包 → 看到"无效"
→ 分不清是规则错了，还是设备还在跑旧版
```

探针 = 在插件里埋一条**只对这个插件生效的可观测规则**。实测前 curl 它：

- 返回版本号 → 设备已加载该版本，可以下结论
- 穿透（返回服务器响应）→ 设备旧版 / 探针有问题，**此时一切"已修复/已生效"的结论作废**

## 2. 唯一合法模板（v1.7.0 锁定，勿手写）

```ini
# [Rewrite] 段内，由 probe-setup.py 生成：
request if ${url} ~= /^https?:\/<域名转义>\/gw\/loon-sim\.probe\.<插件名>/i then reject(200, "<版本>")

# 实例（SMZDM）：
request if ${url} ~= /^https?:\/\/app-api\.smzdm\.com\/gw\/loon-sim\.probe\.smzdm_remove_ads/i then reject(200, "1.4.0")
```

只有 `<域名>`/`<插件名>`/`<版本>` 三个槽位可变。域名选**该插件 [MitM] 列表里的业务域**（保证解密；借道时把借道域加进自己的 [MitM]）。

## 3. check 六项强校验（v1.7.0）

| # | 校验 | 违规级别 |
|---|------|---------|
| ① | 完整锚定 `^https?://域名/.../i`（裸路径等其他形态不允许）| ❌ 错误 |
| ② | `reject(200, "版本")` 双参形态 | ❌ 错误 |
| ③ | 探针版本 = `#!version` | ❌ 错误 |
| ④ | 探针域名 ∈ `[MitM]` 列表 | ⚠️ 警告 |
| ⑤ | 主探针恰好 1 条（防重复埋入）| ❌ 错误 |
| ⑥ | 有 `#!version` 必须有探针 | ⚠️ 警告 |

A/B 对照探针（命名含 `probe.*_bare` / `_bare`）自动豁免 ③⑤ —— 合法共存。

## 4. 工作流

```
改插件 → bump #!version → probe-setup.py <lpx>（埋/更新探针）
→ check（六项自动校验）→ push → 用户更新订阅
→ version-probe.sh <lpx> → ✅ 绿 → 才可终端实测
```

## 5. 穿透排障（三种真因，按发生频率排序）

| 步骤 | 动作 | 真因 |
|------|------|------|
| 1 | **等 5-10 分钟让用户再更新一次订阅** | 订阅刷新延迟（最高频；Loon 更新存在缓存窗口，"已点更新"≠已加载）|
| 2 | 跑 `check`（六项自动查）| 语法/同步错误 |
| 3 | 仍穿透 → **同一插件内**加 `_bare` 探针做真 A/B | 形态差异（2026-10-24 实证：不存在）|

> ⚠️ 同机器同时刻跨插件"一绿一穿"**不能**归因规则形态差异 —— 变量不止一个（各自的订阅刷新状态、规则段完整性）。真 A/B 必须在同一个插件内。

穿透时的识别方法：curl 探针 URL，返回的是**服务器业务响应**（如报错 JSON）= 穿透；返回版本号文本 = 命中。

## 6. 历史事故与设计依据（2026-10-24，五起事故复盘）

| 事故 | 真因 | 固化 |
|------|------|------|
| 清晨穿透×3 → 误判"裸路径不可靠" | probe-setup 生成正则**不闭合** + 订阅延迟混叠 | v1.6.8 闭合校验 |
| 同插件 A/B 实证裸路径可用 | （纠正上文误判）| 排障表第 3 步 |
| JD 穿透 | 纯订阅刷新延迟（虚惊）| 排障表第 1 步置顶 |
| SMZDM 穿透 | /i 缺失 + 重复埋入 + 订阅延迟三层混叠 | v1.6.8/1.6.9 修复+校验 |
| 修后仍穿透 → 再次误判 | 仍订阅延迟；跨插件观察误当 A/B | 方法论：真 A/B 须同插件 |

**为什么探针借插件自己的域（而不是公共域）**：借自己的域 = 验证"这个插件被加载了"（强验证力）；公共域只能验证"Loon 在跑"，且会出现假绿（别的插件把域 MITM 起来，本插件没装照样绿）。模板锁定 = 保留强验证力 + 语法零自由度。

## 7. 失败模式收敛（当前状态）

| 失败模式 | 对策 |
|---------|------|
| 跳过 check 推送 | ci.sh 强制 check |
| 订阅刷新延迟 | 排障表第 1 步（等 + 再更新）|
| 插件 MITM 真失效 | **这正是探针要发现的信息**（借自己域的价值）|
